# CodeAlpha Unemployment Analysis with Python

## 📌 Project Overview
This project analyzes the unemployment rate in India, focusing on the impact of the Covid-19 pandemic and differences between Rural and Urban areas.

## 📊 Dataset
The dataset used is `Unemployment in India.csv`, containing monthly unemployment rates, employment estimates, and labour participation rates across different states.

## 🛠️ Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn (Time-series and Categorical Visualization)

## 🚀 Key Insights
- **Covid-19 Impact:** A massive spike in unemployment occurred in April-May 2020 during the national lockdown.
- **Regional Disparities:** States like Tripura and Haryana consistently showed higher unemployment rates.
- **Rural vs Urban:** Urban areas experienced a sharper spike during the lockdown, but rural areas also saw significant increases.

## 📁 How to Run
1. Clone this repository.
2. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
3. Ensure `Unemployment in India.csv` is in the same directory.
4. Run all cells.
